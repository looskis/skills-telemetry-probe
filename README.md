# skills-telemetry-probe

Test fixtures, not working skills. Each skill here is installed under one condition
(repeat installs from one IP, installs from several IPs, a CI install, an install outside
an AI agent, a user-level install) to measure how [skills.sh](https://www.skills.sh/)
counts installs.

Nothing here does anything. Please don't install these. This repository will be deleted
when the test ends.
